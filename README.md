# mobile-apps-config

Удалённые настройки мобильных приложений komokapps. У каждого приложения своя папка, имя — латиницей через дефис.
Приложения читают файлы по адресу `https://raw.githubusercontent.com/komokapps/mobile-apps-config/main/<папка>/<файл>`
(запасное зеркало — `https://cdn.jsdelivr.net/gh/komokapps/mobile-apps-config@main/<папка>/<файл>`).

| Папка | Приложение | Файлы |
|---|---|---|
| `ryad-za-ryadom` | «Ряд за рядом» — счётчик для вязания (com.komokapps.ryadzaryadom) | `ads.json` — частота рекламы, `privacy-policy.html` — политика конфиденциальности |

Репозиторий публичный: сюда нельзя класть ключи, пароли и другие секреты.
