# «Ряд за рядом» — настройки рекламы

Приложение раз в несколько часов читает файл `ryad-za-ryadom/ads.json` из этого репозитория и показывает
межстраничную рекламу по этим правилам. Менять можно прямо на github.com: открыть `ads.json`,
нажать карандаш, поправить число, «Commit changes». Обновлять приложение не нужно.

| Поле | Что значит | Допустимо | По умолчанию |
|---|---|---|---|
| `ads_enabled` | `false` — межстраничная реклама выключена у всех (аварийный выключатель) | `true` / `false` | `true` |
| `interstitial_per_day` | сколько раз в день максимум; `0` — не показывать | 0–6 (в тестовой сборке до 1000) | 2 |
| `interstitial_interval_hours` | сколько часов минимум между показами | 1–720 (можно дробное, например 6.5; 168 — раз в неделю) | 7 |
| `interstitial_interval_minutes` | интервал в минутах; если поле есть, оно главнее часов. Удобно для проверки | в версии из магазина не меньше 60, в тестовой сборке от 1 | нет |

Значения вне пределов приложение подрезает до ближайшей границы, неизвестные поля пропускает.
Если файл недоступен или испорчен, работают последние сохранённые настройки, а до первой загрузки —
значения по умолчанию.

Новые значения доходят до телефонов не сразу: приложение проверяет файл не чаще раза в 3 часа,
а GitHub и запасное зеркало jsDelivr кэшируют файл от нескольких минут до 12 часов.

Политика конфиденциальности приложения — `privacy-policy.html` в этой же папке
(открытая ссылка через GitHub Pages: https://komokapps.github.io/mobile-apps-config/ryad-za-ryadom/privacy-policy.html).
